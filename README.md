# Fortnite Battle Royale — Browser Edition

## اجرای بازی

فایل `play/index.html` رو توی مرورگر باز کن (دابل کلیک).

**بدون نیاز به سرور** — فقط فایل رو باز کن و بازی کن!

## ساختار پروژه

```
web_game/
├── play/                  ← نسخه قابل اجرا
│   ├── index.html
│   ├── css/style.css
│   └── js/
│       ├── three.min.js    (کتابخانه Three.js)
│       └── game.bundle.js  (کد کامل بازی)
│
├── js/                    ← ماژولهای جداگانه (برای توسعه)
│   ├── vendor/three.min.js
│   ├── core.js            (تنظیمات، ریاضی، نویز، صدا)
│   ├── gfx.js             (رندرینگ، آب، آسمان، پست‌پروسسینگ)
│   ├── world.js           (نقشه، terrain، POI ها)
│   ├── build.js           (سیستم ساخت و ساز)
│   ├── combat.js          (جنگ، سلاح، تیراندازی)
│   ├── chars.js           (شخصیتها، انیمیشن، وسایل نقلیه)
│   ├── ai.js              (هوش مصنوعی باتها)
│   ├── storm.js           (طوفان، بیز، اسکایدایو)
│   ├── drops.js           (supply drop ها)
│   ├── reboot.js          (reboot vans و کارت)
│   ├── ui.js              (رابط کاربری، ورودی)
│   └── main.js            (حلقه بازی، بوت)
│
├── css/style.css
└── README.md
```

## کنترلها

| دکمه | عملکرد |
|-------|--------|
| WASD | حرکت |
| Shift | دونده |
| Mouse | نگاه / نشانه |
| LMB | شلیک / ساخت |
| RMB | ADS (نشانه دقیق) |
| Space | پرش / گلاید |
| Q | حالت ساخت |
| 1-4 | قطعه ساخت (دیوار/کف/رمپ/کنو) |
| G | ادیت ساختمان |
| V | تغییر متریال |
| R | خشابگذاری |
| F | برداشت / احیا / سوار |
| Tab/M | نقشه |
| I | کولهپشتی |
| ESC | تنظیمات |

## ویژگیهای نقشه

- **محدبه کوهستانی NE** — رشتهکوه dramatic با صخرههای عمودی
- **آتشفشان** (-130,-130) — قله بلند با دهانه (crater)
- **دره عمیق SW** — زمین پایینتر برای تنوع بایوم
- **plateau مرکزی** — دشت مرتفع اطراف Tilted Towers
- **صخرههای کناری** — افت dramatic دور تا دور island
